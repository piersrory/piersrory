## How I work

- **The answer key comes first.** I label test data before any model call, so every prompt or model change is measured, not judged by eye.
- **Models copy, code checks.** Every quote and citation a model gives is verified in code.
- **Unknown is never a pass.** When the system isn't sure, a person decides.
- **I write down what doesn't work.** Each repo has a decisions log and a list of known limits.
